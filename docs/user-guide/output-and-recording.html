Output & Recording

Club Visuals provides two ways to get your visuals out of the browser: a dedicated output window for OBS capture or secondary displays, and a built-in recording feature that renders the composite output to MP4.

Output window

The output window is a clean, chrome-free display at http://localhost:8008/output. It mirrors everything the main window does — video, layout, mirror presets, effects, zoom, pan, trails, and captions — but with no controls, buttons, or UI elements.

The output window shows a full-viewport black canvas. When you load a video and change settings in the main window, the output window mirrors those changes in real time — same layout, same presets, same effects — with zero UI chrome.

How synchronisation works

The output window connects to the server via Server-Sent Events (SSE). Every action in the main window — loading a video, changing the layout, applying an effect preset, adjusting zoom — is broadcast to all connected output windows in real time. The output window maintains its own clone system and render loop, driven entirely by these state updates.

Using with OBS

  1. Open the output window at http://localhost:8008/output in a browser
  2. In OBS, add a Window Capture source pointing to the output window
  3. Alternatively, use a Browser Source pointed at http://localhost:8008/output
  4. Control everything from the main window — the output follows automatically

Using with a second display

  1. Open the output window in a second browser window
  2. Drag it to your projector or secondary monitor
  3. Press F11 (or your browser's fullscreen shortcut) to go fullscreen on that display
  4. Control everything from the main window on your primary display
Tip. The output window is muted by default and loops video automatically. This is intentional — audio should come from your DJ setup, not the visuals display. The output window does not have bounce mode, as it is designed for continuous playback.

Recording

The Record button in the Playlist tab captures the composite video output — all tiles, mirror presets, effects, and captions — as a single MP4 file.

Starting a recording

  1. Set up your video, view mode, mirror preset, and effects
  2. Switch to the Playlist tab
  3. Click Record
  4. The button turns red and shows a timer: "REC 00:15"
  5. Play back manually or start a playlist — everything is captured

Stopping a recording

  1. Click the red REC button
  2. If loop or bounce mode is active, the recording waits for the current cycle to complete for a clean ending
  3. The button shows "Stopping..." while it finalises
  4. The WebM capture is uploaded to the server, which converts it to MP4 using ffmpeg
  5. The resulting MP4 appears in your library

Recording details

The recording captures the composite frame including all tile transforms, zoom, pan, and CSS filter effects. Caption overlays are also rendered into the recording.

Note. Recording uses the browser's MediaRecorder API. Long recordings produce large WebM files that must be uploaded to the server for conversion. Ensure you have sufficient disk space in your download directory.
