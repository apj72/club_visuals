Install & Setup

Club Visuals runs as a local Python HTTP server with no external Python dependencies. You need Python, two CLI tools, and a Chromium browser with an active Instagram session.

Requirements

  • Python 3.10+ — ships with macOS or install via brew install python
  • yt-dlp — the download engine. Install: brew install yt-dlp
  • ffmpeg — used for thumbnail generation and recording conversion. Install: brew install ffmpeg
  • A Chromium browser (Brave, Chrome, Edge) with an active Instagram login — Club Visuals reads your browser cookies for authenticated downloads

Clone and run

  1. Clone the repository: 
    git clone https://github.com/apj72/club_visuals.git
cd club_visuals
  2. Start the server: 
    ./start.sh
    This launches the server at http://localhost:8008 and opens it in your default browser.

No pip install or virtual environment is needed — the server uses only the Python standard library.

Stopping the server

./stop.sh

This kills the background server process. You can also press Ctrl+C if you started the server in the foreground with python3 server.py.

Browser setup

By default Club Visuals reads cookies from Brave browser. If you use a different Chromium browser, edit the --cookies-from-browser value in server.py (search for brave and change it to chrome, edge, etc.).

You must be logged into Instagram in your chosen browser before downloading. Club Visuals exports your session cookies — it never stores your Instagram password.

Configuration

App configuration is stored in config.json in the project root. The only setting is the download directory: 

{
  "download_dir": "./downloads"
}

You can change this to any absolute or relative path. The Settings tab in the app provides a visual directory browser for changing this without editing the file.

File locations

PathPurpose
downloads/Downloaded videos (MP4) and metadata (JSON)
thumbnails/Cached video thumbnails (auto-generated)
playlists/Saved playlists as JSON files
.cookies.txtExported browser cookies (auto-managed)
config.jsonApp configuration
Tip. The downloads/, thumbnails/, and playlists/ directories are gitignored. Your video library and playlists live only on your machine.
