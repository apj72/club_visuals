Club Visuals user guide

Build, edit, rehearse, perform and record a complete visual show.

Current redesigned interface · 20 November 2026

This handbook describes the working application at /. It follows the same journey as a performance: organise sources, prepare a look, build a sequence, rehearse its composition, send it to the Mac and capture the result. The classic interface at /classic shares the same saved media and playback engine; some control locations differ.

Your first ten minutes

  1. Start the redesigned server and open Prepare. Select a library video. Choose a layout and mirror pattern, then adjust Zoom and X/Y position.
  2. Open Playlists and select a saved playlist, or start a new one. Click a thumbnail to select its composition.
  3. Click a green timeline block to edit that section's layout, orientation and framing. Click a purple block to edit an effect cue.
  4. Place the playhead with the time ruler. Press Play playlist below the preview. This plays the full composition, including scheduled changes and logo motion. Pause to hold the composed frame.
  5. Click Save beside the playlist name. When you are ready for a display, use Play this playlist on Mac. Preview and saving alone do not take over the live display.

The Private preview toolbar starts rolled up. Click Output controls to show Send to Mac, live playlist, output/fullscreen and iPad buttons; click Hide output controls to roll it up again. This browser remembers your choice. Connection status, command feedback and control-handover actions stay visible.

Know which action you are taking

ActionResult
Preview / Play playlistRuns privately in this editor. It uses the current, including unsaved, composition.
SaveStores this playlist on the Mac server. It does not publish or play it live.
Send to MacTakes the currently prepared look and its state to the live Mac output.
Play this playlist on MacSends the edited playlist to the Mac engine and starts live playlist playback.
Save library in Show BuilderStores reusable models, bricks and DJ profiles; this is separate from saving a generated show.
Capture MP4Renders an export using the selected Capture format. Social and logo captures are silent.

Choose a workspace

Prepare creates an individual look. Library finds and classifies sources. Playlists edits an exact sequence. Show Builder generates sequences from reusable recipes. Auto Perform reacts to music. Capture creates reusable or social-format video. Settings manages folders, connection and preferences.

A useful rehearsal: open the saved VERSION1 · From Signal to Spectacle · 12 min showcase, turn captions off in Prepare's preview options, select 16:9 and keep playlist looping off. The first eight seconds deliberately show SIGNAL on black. Scrub beyond 00:08 for the blue lasers. The showcase media is local to the installation where it was created; a clean checkout does not include the video library.
