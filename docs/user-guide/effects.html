Effects & Audio

The FX Controller is a popup window for colour effects and motion trails. Open it with FX. The separate VFX button opens live GPU scenes, including reflective text and logo shapes.

Opening the FX Controller

Click the FX button in the main window's controls bar. A 400×650 popup window opens. The FX button highlights green to indicate the controller is active. When you close the popup, the button returns to its default state.

The controller communicates with the main window in real time — every slider change is applied instantly to the video and all tile clones.

Transport controls

The top of the FX Controller shows the current video filename and three transport buttons that mirror the main window controls:

  • Play / Pause — toggles playback (green when playing)
  • Loop / Bounce — cycles through playback modes
  • Mute / Unmute — toggles audio

These buttons let you control playback without switching back to the main window — useful when the main window is fullscreen on a second display.

Effect sliders

Seven CSS filter effects are available, each with a dedicated slider:

EffectRangeDefaultDescription
Hue0 – 360°0Rotates the colour wheel. 180° inverts all colours.
Saturate0 – 300%1000% is greyscale, 300% is hyper-saturated.
Contrast50 – 200%100Lower values flatten, higher values punch.
Brightness50 – 200%100Dims or brightens the image.
Blur0 – 10 px0Gaussian blur. Subtle values (0.5–2) create a dreamy look.
Invert0 – 100%0Inverts pixel colours. 100% is a full negative.
Sepia0 – 100%0Warm vintage tone.

All effects are applied as CSS filters, so they render at full frame rate with no performance penalty. Effects are also applied to the output window and to recordings.

Click a preset to apply it. The preset button highlights to show it is active. Moving any slider clears the preset highlight — the preset is a starting point, not a lock.

Reset All

The Reset All button at the bottom of the FX Controller returns every slider to its default value. This instantly removes all effects from the video.

Motion trails

The Trails section adds a ghosting/afterimage effect to all tiles. When enabled, each frame blends into the previous frames instead of replacing them.

  • Toggle button — turns trails on or off
  • Amount slider (0.02 – 0.30) — controls trail opacity. Lower values create longer, more transparent trails; higher values create shorter, more opaque trails.

Trails work with all view modes and mirror presets. They are particularly effective with bounce mode and slow-moving source material. Trails are also visible in the output window and in recordings.

Live VFX on the full output

Click VFX in the player to open its own pop-out controller. Turn GPU effects on or off while the main app keeps playing. VFX processes the complete current layout, including playlist changes and mirror presets. Choose Liquid ripple, Image smear, Video ribbons, Mirror sculpture, Kaleidoscope tunnel, Prism fracture, or 3D Version1 logo, then adjust Intensity and Feedback. With the controller focused, keys 1–7 switch scenes and Space fires a pulse.

The main fullscreen player, the clean output window, and recordings use the active VFX scene. Captions stay above the effects so they remain readable.

Reflective text and branding

After loading a video, click Mirror 3D in the player controls to turn on Mirror sculpture and open its controller. Type a title or Instagram ID, or click Use current video's @ID to use the playing video's metadata. Click Use Version1 logo for the bundled mark, or choose Transparent image and load another PNG or WebP file under 1 MB. Transparent pixels remain open; opaque pixels become the mirror surface.

Position and Size place the shape over the video. Reflection depth bends the image inside and around it; Edge glow highlights its outline. 3D angle, Extrusion, and Motion give the silhouette apparent depth and gentle movement. The live video remains the reflected material, so the branding changes with every clip. These controls create an extruded silhouette effect, not an imported 3D mesh.

3D branding

Click 3D Logo for a solid object extruded from the Version1 SVG, or 3D Text for an editable Instagram ID. The text starts as @tonyt.dj in the Version1 Bungee font, with a red @ and white handle. In the controller, choose Logo or Instagram ID, type new text, and adjust Horizontal position, Vertical position, Size, Depth, and Rotate X/Y/Z. Choose the Auto rotation axis and its start and end angles to make the object sweep within a limited range. Set Auto rotate to zero to hold the manual angle. Both objects are lit, reflect the playing video, and appear in the player, output, and recordings.

Venue audio input

Select a microphone or USB audio interface in the VFX controller and click Connect. The input meter shows live bass energy. Bass drives distortion and sharp rises launch ripples or smears. Adjust Sensitivity for the venue level.

The app analyses the selected live input without playing it through the browser. The video soundtrack does not drive VFX.

Disconnection warning

If you close or reload the main window while the FX Controller is open, a warning banner appears: "Main window disconnected. Close and reopen from the main app." The controller checks every second whether the parent window is still alive.
