Playlists

Playlists let you build cue lists where each entry specifies a video, view mode, mirror preset, loop mode, and duration. Playlists auto-advance through entries and are saved as JSON for reuse across sessions.

Creating a playlist

  1. Click the Playlist tab in the right sidebar
  2. Click New to start a fresh playlist
  3. Type a name in the playlist name field

Adding entries

To reuse a layout you developed for a video, select that video and choose one of its named saved layouts. The form fills in layout, panel orientation, playback method, speed, zoom, and X/Y position. You can also load a saved layout below the main player; this selects the same video and layout in the playlist form. Add captures the visible player layout for the selected video, including any changes made after loading it. The playlist entry stores those values, so it keeps its look even if you later change or delete the saved layout.

For a quicker route, right-click a saved layout below the player (or click its ⋯ button) and choose Add to playlist…. You can also select a video in the Library sidebar and click its + Playlist button, or right-click any Library video. The button appears only on the selected video. Select an existing playlist or create a new one, choose a duration and transition, then click Add to playlist. The entry is saved immediately; Open playlist takes you to the result. A Library video uses its current player layout if selected, or a Single layout otherwise.

Each playlist entry defines a complete visual treatment. To add one:

  1. Click the video picker to open the dropdown and select a video (thumbnail previews are shown). The selected video also loads in the player so you can preview it.
  2. Choose a view mode: Single, Dual, 3x, 4x, or 8x
  3. Choose a preset: P1 through P32
  4. Set the duration type: Loops (number of full video loops) or Seconds (wall-clock time)
  5. Set the duration value
  6. Choose the transition in, duration in seconds, and speed curve
  7. Choose the loop mode: Loop or Bounce
  8. Click Add

Changing the view or preset selector immediately previews the change in the player, so you can see the treatment before adding it.

Available transitions are Cut, Fade In, Fade Out/In, Cross Dissolve, Wipe, Zoom / Spin, Whip Pan, Pixel Scatter, Data Tear, Iris Burst, and Shutters. Pixel Scatter removes shuffled blocks of the outgoing image to reveal the next clip; the incoming clip stays on its first frame until the reveal finishes. Data Tear displaces and removes horizontal strips with colour flashes; Iris Burst opens from the centre; Shutters collapse strips to reveal the image underneath. The effect belongs to the incoming entry and plays when the playlist advances, including when you press Next. Fade In starts from black; Fade Out/In passes through black. Set a duration from 0.15 to 10 seconds. The speed curve controls how motion develops within that exact duration: Even, Build (slow to fast), Hit (fast to slow), or Ease (smooth start and finish). The default for new entries is Cross Dissolve at 0.8 seconds with an Even curve. Existing playlist entries without a transition continue to use Cut. The outgoing frame is held while the next video loads, then the effect runs over the incoming video. The main player's Transition control sets the effect for manually selected videos. Transitions also appear in the clean output and recordings.

The same video can appear multiple times in a playlist with different treatments. For example:

  • Dual mode, preset 5, loop, 10 loops
  • 8x mode, preset 22, loop, 30 seconds
  • 8x mode, preset 7, bounce, 5 loops

Entry list

The timeline shows each video's thumbnail, name, layout, configured run time, and a remove button. A leading "Video by" is hidden from the displayed name. The total at the top estimates the full playlist length. For loop-based entries, the estimate uses source duration, loop count, speed, and Bounce playback; seconds-based entries use their specified slot length. If source duration is unavailable, the card says so and the total shows the known minimum.

  • Drag and drop video cards to reorder them
  • Drag an effect icon from the palette into a transition slot between cards, or select an icon and click a slot
  • Click an entry to preview it in the player (outlined in red while previewing)
  • Click a transition slot to edit its incoming effect, duration, and speed curve, then click Save to keep the change
  • Click Audition above the transition icons to preview the selected effect with library clips. Click ▶ Preview on a slot to start with the two videos around it; the first slot starts from black. In the audition window, choose clips, effect, duration, and speed curve, then click ▶ Replay. Use in slot applies the settings to that entry; click Save to keep it. The preview does not interrupt the main player or clean output.
  • Click ✦ Script effects on a video card to add timed VFX cues. Each cue starts a scene, mirror, 3D logo, or 3D text at a chosen number of seconds into that video. Set intensity and feedback, and for objects set text, position, size, rotation axis, angles, and rotation speed. Add an Off cue to end the effect. Cues run in time order and follow the video if you reorder the cards.
  • Click ✦ Auto-script effects to add a varied set of VFX cues to videos that have none. Longer entries get a second cue later in the video. Existing cue scripts are preserved. Review each video's cues, then click Save.
  • Click the × button to remove an entry

Saving and loading

  • Click Save to persist the playlist to the server as a JSON file
  • Use the playlist dropdown at the top to load a previously saved playlist
  • Click Del to delete the current playlist (a confirmation dialog appears)

Playlists are saved in the playlists/ directory as JSON files named by a slug derived from the playlist name. They survive server restarts and page reloads.

Playing a playlist

  1. Click Play to start from the first entry
  2. The playlist indicator bar appears above the video showing: current entry number, view/preset info, and loop progress
  3. Entries auto-advance when their duration expires
  4. Click Next in the indicator bar to skip to the next entry
  5. Click Stop to exit playlist mode

During playback, the current entry is highlighted with a green border in the entry list.

Timed effect cues run relative to the start of their video. Pressing Next cancels pending cues for the previous entry. Stopping the playlist restores the VFX settings that were active before playback. Cue changes are sent to the clean output and included in recordings.

Playlist looping

Click Loop: Off to toggle playlist looping. When on, the playlist restarts from the first entry after the last one completes. The button shows Loop: On when active.

Auto-generating playlists

Click Auto to reveal the auto-generate form:

  1. Set the target duration in minutes (1–480, default 30)
  2. Optionally tick Select videos to choose which videos to include. An "All" / "None" bar appears with checkboxes on each library item.
  3. Click Generate

The generator:

  • Fetches duration metadata for the selected (or all) videos
  • Shuffles videos randomly
  • For each entry: picks a random view mode, a random preset from that mode's curated set, and 1–5 random loops
  • Fills entries until the total estimated time exceeds the target
  • Names the playlist "Auto Nmin"

A status message shows the result: e.g. "15 entries, ~32 minutes total". Click Save to keep the generated playlist.

Tip. Auto-generate is great for building a baseline set. Generate a 30-minute playlist, then manually edit individual entries — swap presets, adjust durations, reorder the sequence — to fine-tune the visual story.
